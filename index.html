Aplikaci se nepodařilo spustit. Potřebuje JavaScript a webový server: GitHub Pages, npm run dev nebo npm run preview. Když index.html otevřete přímo z disku, prohlížeč aplikaci zablokuje.

Die App konnte nicht gestartet werden. Sie braucht JavaScript und einen Webserver: GitHub Pages, npm run dev oder npm run preview. Wenn Sie index.html direkt von der Festplatte öffnen, blockiert der Browser die App.
